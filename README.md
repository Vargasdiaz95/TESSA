# TESSA

## Tecnossystem Smart Setup Assistant

TESSA es una plataforma modular desarrollada por Tecnossystem para automatizar los procesos de alistamiento, configuración, personalización e inventario de equipos Windows.

Nace como la evolución de AIMT (Asistente de Instalación y Mejoras Tecnossystem), incorporando una arquitectura modular, reutilizable y escalable que permite soportar múltiples perfiles de organización a partir de una única base de código.

---

## Objetivo

Estandarizar y automatizar las actividades técnicas requeridas para la preparación y entrega de equipos corporativos, reduciendo tiempos operativos, minimizando errores manuales y facilitando la administración de configuraciones específicas para diferentes organizaciones.

---

## Características

- Automatización de tareas de alistamiento.
- Instalación de controladores.
- Personalización corporativa.
- Gestión de usuarios.
- Gestión del archivo Hosts.
- Recolección de inventario.
- Registro de actividades.
- Arquitectura basada en perfiles.
- Plataforma escalable y reutilizable.

---

## Arquitectura General

TESSA se compone de tres componentes principales:

### Core

Contiene la lógica reutilizable de la plataforma.

### Perfiles

Contiene las configuraciones específicas de cada organización.

### Recursos

Contiene componentes, instaladores, plantillas y elementos compartidos.
